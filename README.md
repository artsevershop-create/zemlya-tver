# Сайт «Земля в Старицком округе»

Статичный сайт для продажи участков сельхозземли в Старицком округе Тверской области:
3D-схема на рельефе, разделы для сельского хозяйства, туризма, бизнеса и государства,
расчётные варианты раздела участков, каталог и форма запроса.

Готовый сайт лежит в папке `site`: сборка не нужна, её можно выложить на любой хостинг.

## Посмотреть локально

```bash
node tools/server.js
```

Откроется на http://localhost:4173.

## Что менять

- `site/js/config.js`: контакты продавца, показ цен, плашка «Предварительная версия».
- `data/registry.csv`: участки из свидетельств (номер, площадь, ориентир, расстояние до него).
- Ставки цен по классам: `RATE` в `tools/build.js`.
- Тексты разделов по аудиториям: массив `AUD` в `site/js/app.js`.

## Обновить данные

```bash
npm install
node --use-system-ca tools/fetch.js
node tools/build.js
```

`fetch.js` скачивает в `data/raw` границы участков (НСПД), дороги и реки (OpenStreetMap), рельеф
и расстояния по дорогам. Чтобы перекачать заново, удалите нужные файлы из `data/raw`.
`build.js` собирает из них `site/data` и копирует библиотеку и шрифты в `site`.

## Обновить сайт на GitHub Pages

Сайт публикуется из ветки `gh-pages`, в которой лежит содержимое папки `site`:

```bash
git push origin main
git push origin "$(git subtree split --prefix site main)":gh-pages --force
```

## Что сделать до рекламы сайта

- Подтвердить права на участки по выпискам ЕГРН и убрать из каталога лишнее.
- Заполнить контакты и поставить `draft: false` в `site/js/config.js`.
- Убрать `<meta name="robots" content="noindex">` из `site/index.html`: сейчас сайт закрыт от поисковиков.

## Источники данных

- Границы и характеристики участков: НСПД (Росреестр).

- Рельеф: Terrain Tiles (Mapzen), данные SRTM.
- Расстояния по дорогам: OSRM.
- Шрифты: Golos Text и Sofia Sans Extra Condensed (SIL Open Font License). 3D: three.js (MIT).
